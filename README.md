# English Tools

Windows 桌面英语学习工具：**系统级划词翻译**（任意软件选中英文 → 附近弹出中文）+ 面板内中文实时译英文。翻译使用 DeepSeek API。

YouTube 沉浸学习后续开发。

## 功能

1. **系统划词英译汉**：后台托盘运行，监测鼠标拖选；松手后读取选中文本并在光标附近弹出中文  
2. **汉译英面板**：托盘打开面板，输入中文，下方实时出英文  
3. 可在设置 / 托盘菜单开关「划词翻译」

> 说明：划词通过「拖选松手 → 模拟复制读取选区」实现，适用于记事本、浏览器、Office 等可选中文本的场景。图片/视频内不可选文字不在此范围。

## 开发运行

```bash
npm install
npm run dev
```

首次在「设置」填写 DeepSeek API Key。关闭主窗口会隐藏到托盘，从托盘「退出」才真正退出。

## 可选

`extension/` 目录是早期浏览器扩展原型，**不是**当前主方案；系统划词请用 Electron 桌面端。
